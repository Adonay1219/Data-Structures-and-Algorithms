# Version Control System Simulator (C++)

A collaborative Data Structures and Algorithms group project developed at Mekelle University.

## Overview

This project implements a simplified Version Control System (VCS) simulator in C++. It demonstrates how data structures and algorithms can be applied to model version history and manage version-control operations.

## Implementation

The C++ source code is located at [`implementation/v_c_s.cpp`](implementation/v_c_s.cpp).

## Documentation

The `DOCUMENTATION/` directory contains two project documents:

- **Pseudocode, Algorithm Design, and Time Complexity Analysis:** Describes the algorithms, their design, and their computational complexity.
- **VCS Walkthrough of an Implementation:** Explains the implementation and how the system works.

## Requirements

- A C++ compiler, such as GCC or MinGW.
- A terminal or C++ development environment.

## How to Compile and Run

From the project root directory, compile the source code using:

```bash
g++ implementation/v_c_s.cpp -o vcs
```

On Windows PowerShell, run the executable with:

```powershell
.\vcs.exe
```

On Linux, run it with:

```bash
./vcs
```

## Academic Context

This project was developed collaboratively as a university group assignment at Mekelle University. It applies concepts in data structures, algorithm design, time-complexity analysis, and C++ programming.
